ربط متجر WooCommerce بنظام ShipGo (WMS/OMS): إرسال الطلبات للمستودع وحجز الكميات
وإعادة تحديث حالة الطلب والتتبّع آليًا. يدعم وضع المراقبة (Sandbox) قبل التفعيل المباشر.

== كيف يعمل ==
1. الطلب الجديد في المتجر يُرسَل (لا تزامنيًا عبر WP-Cron، فلا يُبطّئ الدفع) إلى:
   POST {ShipGo}/v1/channel/orders  — مع مفتاح API (Bearer sk_…) ومفتاح Idempotency.
2. ShipGo يطابق المنتجات بالـSKU (الباركود)، ينشئ الطلب، وفي الوضع المباشر يحجز الكميات.
3. عند تقدّم الطلب في المستودع (حجز/تجهيز/تغليف/شحن) يرسل ShipGo تحديث حالة موقّعًا
   (HMAC) إلى: POST {store}/wp-json/shipgo/v1/order-status — فتُحدَّث حالة الطلب والتتبّع.

== الإعداد ==
1. في ShipGo: أنشئ اتصال متجر WooCommerce، ثم أصدر «مفتاح API» (يظهر مرة واحدة) ومعه
   «سر التوقيع» (webhook secret).
2. في المتجر: لوحة الإدارة → ShipGo → الصق رابط ShipGo + مفتاح API + سر التوقيع،
   فعّل الربط، ثم اضغط «اختبار الاتصال».
3. شغّل «فحص المطابقة» للتأكد من تطابق منتجات المتجر مع كاتالوج ShipGo.
4. ابدأ بوضع المراقبة (مفتاح sk_test_): الطلبات تُرسَل وتظهر في ShipGo دون حجز فعلي.
   عند الجاهزية، فعّل «Go Live» في ShipGo وأعد إصدار مفتاح (sk_live_) وحدّثه هنا.

== الأمان ==
- لا يُخزَّن مفتاح API كاملًا في الواجهة (يُعرض مقنّعًا).
- تحديثات الحالة الواردة تُتحقّق بتوقيع HMAC-SHA256 ونافذة زمنية ±5 دقائق ومنع التكرار.
