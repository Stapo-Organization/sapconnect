# 01 — نظرة شاملة على المشروع

## المشكلة

تحتاج شركة Muntajat (PPTCO) لمتجر إلكتروني لمنتجات الحيوانات الأليفة تحت علامة **Zooboxi** مع:

1. **تعدد مستودعات** حقيقي مربوط بنظام SAP عبر sapconnect
2. **توصيل ذكي** بناءً على موقع العميل الجغرافي
3. **مزامنة فورية** للمخزون والأسعار من SAP

## الحل

متجر WooCommerce مع **Custom Plugin** يدير:
- منطق المستودعات المتعددة
- تحديد المستودع الأنسب للعميل
- مزامنة البيانات مع sapconnect API

## المنتجات

### مصدر المنتجات

المنتجات تأتي من جدول `products` في sapconnect، لكن **ليست كل المنتجات** تُعرض في zooboxi.

**الآلية**: إضافة حقل `woo_sync` (boolean) لجدول `products` في sapconnect:
- `woo_sync = 1` → المنتج يُنشر في WooCommerce
- `woo_sync = 0` أو `NULL` → المنتج لا يُنشر

### بيانات المنتج

| حقل sapconnect | حقل WooCommerce | ملاحظات |
|----------------|-----------------|---------|
| `item_code` | `sku` | المعرف الفريد |
| `item_name` | `name` (عربي) | الاسم بالعربي |
| `foreign_name` | `name` (إنجليزي) | الاسم بالإنجليزي |
| `items_group_code` → Brand | `category` | التصنيف/البراند |
| `prices` (JSON) | `regular_price`, `sale_price` | الأسعار من price lists |
| `piece_barcode` | `meta: _barcode` | الباركود |
| `inventory_uom` | `meta: _uom` | وحدة القياس |
| `u_proprt1-5` | `attributes` | خصائص المنتج |
| `image_url` | `images` | `https://ppte.sa/imghd/...` |

---

## التسعير

الأسعار تأتي من SAP عبر حقل `prices` (JSON) في جدول `products`:

```json
{
  "1": {"price": 45.00, "currency": "SAR", "name": "سعر التجزئة"},
  "2": {"price": 38.00, "currency": "SAR", "name": "سعر الجملة"},
  "3": {"price": 42.00, "currency": "SAR", "name": "سعر VIP"}
}
```

**في WooCommerce**:
- السعر الأساسي = Price List 1 (تجزئة)
- يمكن إضافة أسعار مخصصة لاحقاً بناءً على فئة العميل

## المخاطر والتحديات

| المخاطر | الحل المقترح |
|---------|-------------|
| Shared hosting قد لا يتحمل الحِمل | Cache aggressively + CDN + أداء محسّن |
| تأخر المزامنة = بيع منتج غير متوفر | مزامنة مخزون كل 5-10 دقائق + تحقق عند Checkout |
| GPS غير دقيق للعميل | Fallback على اختيار المدينة يدوياً |
| أسعار SAP تتغير | Webhook notification عند تحديث الأسعار |
