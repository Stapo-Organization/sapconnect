# Zooboxi — زوبوكسي

Customer app for the Zooboxi pet store (store.zooboxi.com). Flutter, iOS +
Android, Arabic-first with English.

```bash
flutter pub get
flutter run --dart-define=ZB_BASE_URL=https://store.zooboxi.com/wp-json/zooboxi/v2
```

See [ARCHITECTURE.md](ARCHITECTURE.md) for the structure, the API contract, the
state model, and what is built versus stubbed.
